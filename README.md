# 📁 智能文件夹整理工具

一个基于 Python 和 CustomTkinter 的现代化文件夹自动整理工具，支持按文件类型或修改日期快速归类，并提供预览、进度显示和撤销功能。

## ✨ 主要功能

- **双模式整理**
  - **按文件类型**：图片、文档、视频、音乐、压缩包、代码等自动归入对应子文件夹。
  - **按修改日期**：根据文件修改时间，按 `年-月` 或 `年-月-日` 创建子文件夹。
- **操作方式可选**：支持**移动**或**复制**文件。
- **目标目录自定义**：可选择将整理后的文件输出到不同的根目录。
- **预览机制**：正式整理前可扫描并查看所有文件将如何归类，确认后再执行。
- **进度反馈**：整理过程中通过进度条直观显示进度。
- **一键撤销**：每次整理后自动生成撤销日志，可一键将文件恢复到原始位置。
- **现代化 UI**：基于 CustomTkinter 的深色主题界面，圆角组件，美观易用。
- **跨平台兼容**：Windows、macOS、Linux 均可运行（需满足依赖环境）。

## 🚀 快速开始

### 环境要求

- Python 3.7 或更高版本
- 依赖库：`customtkinter`

### 安装步骤

1. **克隆或下载本仓库**
   ```bash
   git clone <仓库地址>
   cd 文件夹整理工具
   ```

2. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```
   （若无 `requirements.txt`，请手动执行 `pip install customtkinter`）

3. **运行程序**
   ```bash
   python file_organizer.py
   ```

### 打包成独立 EXE（Windows 推荐）

1. **安装 PyInstaller**
   ```bash
   pip install pyinstaller
   ```

2. **准备图标文件（可选）**
   将 `icon.ico` 放在项目根目录。

3. **执行打包命令**
   ```bash
   pyinstaller --onefile --windowed --icon=icon.ico file_organizer.py
   ```
   - 生成的可执行文件位于 `dist/` 目录下。
   - 若提示缺少 `customtkinter` 主题，可添加 `--add-data` 参数手动包含。

## 📖 使用说明

1. 启动程序后，点击“浏览”选择需要整理的**源文件夹**。
2. （可选）选择**目标根目录**。留空则子文件夹直接创建在源文件夹内。
3. 选择**整理方式**：
   - **按文件类型**：自动识别扩展名并归类到“图片”“文档”等文件夹。
   - **按修改日期**：按年-月或年-月-日生成日期文件夹。
4. 选择**操作方式**：移动或复制文件。
5. 点击 **🔍 预览整理效果** 查看扫描结果。
6. 确认无误后，点击 **⚡ 开始整理** 执行操作。
7. 如需恢复，点击 **↩️ 撤销上一次整理**，文件将回到原始位置。

> **注意**：撤销功能仅对最近一次整理操作有效，且依赖同目录下的 `undo_log.json` 文件（请勿手动删除）。

## 📁 文件结构

```
.
├── file_organizer.py      # 主程序源代码
├── README.md              # 项目说明文档
├── requirements.txt       # 依赖列表（可选）
└── undo_log.json          # 撤销日志（程序运行后自动生成）
```

## ⚙️ 自定义文件分类

如需修改文件类型分类，可在源码 `FILE_CATEGORIES` 字典中增删扩展名或调整类别。例如添加“字体”类别：

```python
FILE_CATEGORIES = {
    ...
    "字体": [".ttf", ".otf", ".woff", ".woff2"],
    "其他": []
}
```
